# Calculadora de Conversão Binária

Todos os arquivos ficam no mesmo diretório:

    calculadora-binaria-web/
    ├── app.py
    ├── index.html
    ├── style.css
    ├── script.js
    ├── requirements.txt
    └── README.md

## Instalação no Windows

Abra o CMD dentro da pasta do projeto:

    python -m venv venv
    venv\Scripts\activate
    python -m pip install -r requirements.txt

## Executar

    python app.py

Abra:

    http://localhost:5000

O frontend é HTML + CSS + JavaScript e o processamento das conversões é feito pelo Python + Flask.
